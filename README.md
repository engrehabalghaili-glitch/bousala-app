# بوصلة — نظام هادئ لترتيب الأهداف

تطبيق ويب عربي بالكامل (RTL) لإدارة الأهداف بفلسفة «المقاعد الثلاثة»: بدل مطاردة عشرات الأهداف، تحتفظ بثلاثة مقاعد نشطة فقط — **مقعد طويل واحد + مقعدان قصيران** — وكل ما عاد ينتظر في قائمة «القادمة» حتى يشغر مقعد.

> رتّب أهدافك، تخلّص من الشتات، وابدأ.

## الفلسفة والقواعد

- **لا مواعيد نهائية**: لا حقول تاريخ استحقاق، لا مؤقتات، لا عدّ تنازلي في أي شاشة.
- **لا جداول يومية ولا عدّادات**: التقدم يُدوَّن بحرية (ملاحظات)، دون ضغط كمّي.
- **ثلاثة مقاعد فقط**: هدف طويل واحد + هدفان قصيران نشطون في آن واحد.
- **الإضافة تذهب دائماً إلى القائمة**: زر «+» العام يضيف إلى قائمة الأهداف القادمة (Backlog) ولا يشغل المقاعد.
- **ترقية تلقائية**: عند إتمام هدف يشغر مقعده، ويقترح التطبيق فوراً الهدف التالي من القائمة بنفس النوع.
- **لا حذف قسري**: أثناء الغربلة يمكنك فقط «تأجيل» أو «استبعاد» الهدف — لا شيء يُمحى من الوجود.

## التقنيات

- **Next.js 16** (App Router) + **TypeScript 5**
- **Tailwind CSS 4** — لوحتا ألوان مخصصتان `zen` (رمادي هادئ) و`sage` (أخضر مطمئن)، وضع ليلي كامل (`class` strategy)
- **Zustand** مع `persist` — خزنة محلية في المتصفح (localStorage) باسم `boslah-offline-vault`
- **framer-motion** للانتقالات الناعمة، **@dnd-kit** للسحب والإفلات، **lucide-react** للأيقونات
- خط **Tajawal** العربي، راوتر خفيف عبر الـ hash دون مكتبات إضافية
- التطبيق يعمل **دون اتصال** ولا يرسل أي بيانات لأي خادم؛ قاعدة البيانات (Prisma/SQLite) اختيارية وغير مستخدمة في التشغيل اليومي

## التشغيل المحلي

```bash

bun install
# أو
npm install

# 2) تشغيل خادم التطوير
bun run dev
# أو
npm run dev

# 3) افتح المتصفح على
# http://localhost:3000
```

للنشر كإنتاج:

```bash
bun run build && bun run start
```

## البيانات والنسخ الاحتياطي

- كل بياناتك تُحفظ محلياً في متصفحك فقط (localStorage).
- من **الإعدادات** يمكنك **تصدير** نسخة احتياطية JSON مؤرخة، و**استيرادها** على أي جهاز مع تحقق من السلامة.
- «إعادة الرحلة» تمحو كل شيء بعد تأكيد مزدوج صريح.

## ملاحظات

- التطبيق مصمم Mobile-First (حاوية بعرض هاتف في وسط الشاشة على الحواسيب) وجاهز للعمل كتطبيق PWA عبر ملف manifest المرفق.
